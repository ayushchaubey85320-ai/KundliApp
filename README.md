# KundliApp - Vedic Astrology Mobile Application

A modern, high-precision Vedic Astrology (Kundli / Janam Patri) mobile application built with React, TypeScript, and Vite.

## Features
- **Vedic Ephemeris Engine**: Accurate planetary positions, Lahiri Ayanamsha, and Ascendant (Lagna) calculations.
- **Divisional Charts**: Interactive D1 (Lagna / Rashi) and D9 (Navamsha) charts.
- **Regional Chart Styles**: North Indian (Diamond) and South Indian (Square) chart renderers with house inspections.
- **Planetary Positions & Dignity**: Detailed table of Grahas, Rashis, Nakshatras, Padas, Exaltation/Debilitation, and Retrograde status.
- **Vimshottari Dasha**: 120-year cycle breakdown (Mahadasha and Antardasha timeline).
- **Dosha Analysis**: Manglik Dosha, Kaal Sarp Dosha, and Sade Sati detection with classical remedies.
- **Kundli Milan**: 36 Guna Ashtakoot matchmaking with comprehensive compatibility scoring.
- **City Database & GPS**: 500+ pre-bundled Indian & international cities with coordinates and timezones, plus GPS auto-detection.
- **Mobile-First & PWA**: Designed for mobile touch interaction, installable as a PWA, and deployable to Render / Android APK.

## Deployment on Render
1. Connect this GitHub repository (`https://github.com/ayushchaubey85320-ai/KundliApp.git`) to Render.
2. Select **Static Site**.
3. Set **Build Command**: `npm run build`
4. Set **Publish Directory**: `dist`
